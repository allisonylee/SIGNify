Translator check

On-device translation support, per language pair

Chrome reports every language pair as downloadable until a site actually creates a translator for it — it hides real pack availability for privacy. So only the Create column is meaningful; availability cannot tell us whether a pair works.

When creation fails, Chrome throws a deliberately generic NotSupportedError but logs the specific reason as a console warning. Open DevTools → Console before running this to see why a pair was refused.

Every create() is fired at once, inside the click, because downloading a pack needs user activation and awaiting pairs one by one would spend it before the later ones ran. First run may take a while per pack.
